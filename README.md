# ABIEncoderDemo

Foundry study project with simple Solidity examples of:

- `abi.encode` and `abi.decode`
- `abi.encodePacked`
- `keccak256` identifiers
- Encoding data for swaps, orders, flash loans, staking, yield strategies, and bridges
